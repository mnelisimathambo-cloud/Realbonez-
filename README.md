# Real BoneZ Premium Website

This is a free static website built for GitHub Pages.

## Publish it free

1. Create a free GitHub account.
2. Create a new public repository named `realbonez`.
3. Upload every file and folder from this package.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root`.
7. Save.

Your website will appear at:

`https://YOUR-GITHUB-USERNAME.github.io/realbonez/`
